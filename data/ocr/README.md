# OCR Runtime Models

These are PaddleOCR 2.8.1 inference models converted to ONNX opset 14 with
Paddle2ONNX 1.3.1.

- `ocr_detector.onnx`: `en_PP-OCRv3_det_infer`
- `ocr_model.onnx`: `en_PP-OCRv4_rec_infer`
- `ocr_dict.txt`: PaddleOCR `ppocr/utils/en_dict.txt`

Sources:

- https://paddleocr.bj.bcebos.com/PP-OCRv3/english/en_PP-OCRv3_det_infer.tar
- https://paddleocr.bj.bcebos.com/PP-OCRv4/english/en_PP-OCRv4_rec_infer.tar
